# Blender 齿轮生成器插件

此插件可为 Blender 5.1 生成参数化齿轮模型。

## 功能
- 可调节齿数
- 可调节模数和厚度
- 齿型：直齿、斜齿、人字齿
- 齿轮类型：外齿轮、内齿轮、齿形齿轮、齿条
- 齿轮配对：平行轴、交错轴、倾斜轴、内外啮合

## 安装
1. 将 `gear_generator_addon` 文件夹复制到 Blender 插件目录（C:\Users\用户名\AppData\Roaming\Blender Foundation\Blender\5.1\scripts\addons），或在 Blender 中通过“从文件安装...”安装。
2. 在 Blender 首选项 → 插件 中启用“齿轮生成器 5.1”。
3. 在 3D 视图侧边栏中打开“齿轮生成器”面板。

## 使用
- 选择齿轮类型和齿型
- 设置齿数、模数、厚度、压力角、螺旋角
- 单击“生成齿轮”
